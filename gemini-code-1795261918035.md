### 1. Core Concept & Visual Identity
The website is a multi-mode file transfer and social web application designed to run on a free-tier stack: GitHub for source control, Render (`yourapp.onrender.com`) for static hosting, Firebase Firestore and Firebase Authentication (Spark plan) for database, signaling, accounts, and feedback, a Progressive Web App (PWA) service worker for offline shell caching, Cloudflare Turnstile for bot checks, and a Cloudflare Worker for security/hash checks and alert logging.

Visually, the idea is intentionally clean, technical, and non-generic—modeled after Linear, Raycast, and Vercel interfaces. It uses a matte dark palette (`#0A0A0A` page background, `#121212` panels, `#171717` subpanels), subtle `1px solid #262626` borders, high-contrast off-white text (`#EDEDED`), muted gray labels (`#8A8A8A`), a single accent color, and `Inter` + `JetBrains Mono` typography. It avoids emojis in UI headings, buttons, or labels in favor of clean monochrome SVG icons, and avoids repetitive "card grid soup" in favor of focused workspaces, tabs, and clear dividers.

### 2. Transfer Modes, Roles & Size Handling
Users can choose between **Receiver** and **Sender** roles and switch across three transfer modes:
- **Global P2P (Heavy):** Receiver creates a 6-digit room code and QR code; Sender joins and streams files directly peer-to-peer over a WebRTC `DataChannel` without storing full files on servers. Heavy files (such as 3 GB+) are sliced into **64 KB chunks** (`file.slice()`) with `bufferedAmount` backpressure control so browser memory does not spike, support pause/resume by chunk index, and stream straight to disk on supported browsers (`showSaveFilePicker`) with a safe memory fallback and user-adjustable size limit caps (accounting for desktop vs. mobile browser RAM constraints).
- **Async Drop (up to 700 KB):** For small files or text sent asynchronously through Firestore when both users are not online at the exact same moment, kept strictly under ~700 KB to stay safely within Firestore's 1 MiB document limit.
- **Zero-Internet Local Mode:** Allows users with a cached PWA shell over local Wi-Fi or a mobile hotspot without internet access to pair via an offline QR code / SDP handshake and stream files directly over the local network.

### 3. Security, Social Layer, Feedback & Owner-Only Admin
- **Security & Bot Protection:** Cloudflare Turnstile verifies human interaction before key actions; files have a client-side SHA-256 hash computed locally and checked against a Cloudflare Worker endpoint alongside file extension checks, warning receivers of risky file types and logging alerts.
- **Ephemeral Chat, Accounts & Friends:** Active rooms include a temporary chat stored in Firestore that clears when the room closes or expires after 2 hours. Users can sign in with Google via Firebase Auth, receive a unique permanent Friend ID (`users/{uid}`), send/accept friend requests, and send direct room invites.
- **Feedback:** Submitted directly into a Firestore `feedback` collection so users can send reports/suggestions and the owner can manage them without needing a separate third-party form service.
- **Owner-Only Admin:** Locked strictly to the owner's Firebase UID (`request.auth.uid == ADMIN_UID` in Firestore rules and checked in the UI). It lets the owner view transfer metadata logs, Cloudflare Worker security alerts, and user feedback, and update live settings (`config/appSettings`) such as the Cloudflare Worker URL, Turnstile key, maintenance banner, and blocked extensions. Because P2P transfers stream directly between peers, heavy P2P files are not stored on servers for later admin download.

### 4. Complete Function Map
Here are all the functions that define how the application works:

**Navigation, UI & App State**
- `navigate(viewName)`: Switches between the Transfer, Friends, Feedback, and Admin views and keeps navigation state synced.
- `setTransferMode(mode)`: Switches between Global P2P (Heavy), Async Drop (up to 700 KB), and Zero-Internet Local mode, adjusting limits and visible controls.
- `setRole(role)`: Switches the active role between Receiver and Sender.
- `updateMaxSizeCap(megabytes)`: Updates the file size limit cap and enforces safe browser memory thresholds.
- `syncNetworkStatus()`: Tracks online/offline browser state and updates status badges/indicators.
- `loadAppConfig()`: Loads live configuration from `config/appSettings` in Firestore (Worker URL, Turnstile site key, maintenance banner, blocked extensions).
- `renderMaintenanceBanner(text)`: Displays or hides the top announcement/maintenance banner based on configuration.

**Authentication, User IDs & Friends**
- `signInWithGoogle()`: Authenticates the user with Google via Firebase Auth.
- `signOutUser()`: Signs the user out and clears authenticated/admin views.
- `ensureUserProfile(user)`: Creates or loads `users/{uid}` in Firestore and assigns a unique Friend ID if missing.
- `sendFriendRequest(targetFriendId)`: Looks up a user by Friend ID and creates a pending friend request in Firestore.
- `respondToFriendRequest(requestId, accept)`: Accepts or declines a friend request and links friends in Firestore when accepted.
- `listenToFriendsAndInvites(uid)`: Listens in real time for friend updates, incoming requests, and room invites.
- `sendRoomInvite(friendUid, roomCode)`: Sends a direct room invite to a friend.

**Room Pairing, QR Codes & Offline Handshake**
- `createTransferRoom()`: Generates a 6-digit room code and QR code, creates a 2-hour signaling room in Firestore, and starts the expiry timer.
- `joinTransferRoom(code)`: Connects a sender to a 6-digit room and initiates WebRTC signaling.
- `destroyCurrentRoom()`: Deletes the room and its temporary messages from Firestore, closes peer connections, and resets state.
- `startRoomExpiryTimer(expiresAt)`: Tracks the 2-hour room lifetime and auto-closes/cleans up expired rooms.
- `generateOfflineOffer()`: Creates a local WebRTC SDP offer and encodes it as a QR code for offline pairing.
- `generateOfflineAnswer(offerJson)`: Processes a scanned/pasted offline offer and generates an answer QR code.
- `applyOfflineAnswer(answerJson)`: Applies the offline answer on the receiver side to establish the local WebRTC connection.
- `startQrScanner(targetRole)` & `stopQrScanner()`: Starts and stops camera-based QR scanning cleanly.

**Security, Bot Check & Chunked Streaming**
- `verifyTurnstileToken(token)`: Validates Cloudflare Turnstile tokens before allowing protected actions.
- `computeFileSha256(file)`: Computes a SHA-256 hash of a file locally in the browser.
- `checkFileSecurityWithWorker(fileMeta, sha256Hash)`: Checks blocked extensions and queries the configured Cloudflare Worker URL for threat/hash status.
- `sendFileInChunks(file, dataChannel)`: Slices files into 64 KB chunks via `file.slice()` with `bufferedAmount` flow control and chunk sequence numbers.
- `togglePauseTransfer()` & `resumeFromChunk(chunkIndex)`: Pauses transfers and resumes from a specific chunk index if interrupted.
- `receiveChunkAndSave(chunkMessage)`: Streams incoming chunks directly to disk when supported or assembles them into a file download, and records transfer metadata.
- `sendAsyncDrop(file)`: Handles small files/text (up to ~700 KB) stored temporarily in Firestore for async retrieval.

**Ephemeral Chat, Feedback, Admin, Worker & PWA**
- `sendChatMessage(text)` & `listenToRoomChat(roomCode)`: Sends and streams temporary messages inside an active room, wiped on close or 2-hour expiry.
- `submitFeedback(category, message)`: Saves validated user feedback into Firestore's `feedback` collection.
- `isCurrentUserAdmin()`: Verifies that the signed-in user matches the owner's Firebase UID before showing or allowing admin actions.
- `saveAdminConfig(settingsObj)`: Saves Worker URL, Turnstile key, maintenance banner, and blocked extensions to `config/appSettings` in Firestore.
- `loadAdminAnalytics()`: Loads transfer metadata logs, Cloudflare Worker security alerts, and feedback entries for the admin view.
- Cloudflare Worker functions (`handleRequest`, `lookupHashThreat`, `logSecurityAlert`): Handle CORS/requests, check file hashes against threat intelligence, and log security alerts.
- PWA service worker handlers (`install`, `activate`, `fetch` in `sw.js` + `manifest.json`): Cache the app shell for offline opening while passing online API/Firebase/Turnstile/Worker traffic through.
